# Course 00 — Azure AI Infrastructure Engineer — Getting Started

## Outcome

Prepare a reproducible workstation and understand the engineering evidence required for every subsequent Azure AI lab.

## Lessons

1. Academy engineering mindset
2. Workstation and toolchain
3. Azure CLI and identity context
4. Terraform CLI
5. Azure resource lifecycle
6. Validation and evidence
7. Break/Fix discipline

## Labs

- 00-01 Environment Discovery
- 00-02 Azure CLI Authentication
- 00-03 Terraform Installation
- 00-04 First Azure Resource
- 00-05 Environment Validation
- 00-06 Break/Fix — Wrong Subscription
- 00-07 Challenge — Rebuild Your Environment

## Definition of Done

The learner can independently prove that the workstation, Azure context and Terraform toolchain are ready without exposing credentials.
