# Course 00 — Azure AI Infrastructure Engineer — Getting Started

**Level:** Beginner | **Mode:** Build-first | **Prerequisites:** Basic Windows/Linux command-line usage

## Mission

Prepare a reproducible engineering workstation for Azure, Terraform and Microsoft Foundry work.

## Modules

### 00.1 Engineering Mindset
IaC, reproducibility, evidence-driven engineering and Git workflow.

### 00.2 Developer Workstation
Git, VS Code, PowerShell, Azure CLI and Terraform CLI.

### 00.3 Azure Identity
Tenant, subscription, account, authentication and RBAC basics.

### 00.4 Lab Environment
Create and validate a learner-owned training environment.

## Labs

- LAB 00-01 — Environment Discovery
- LAB 00-02 — Azure CLI Authentication
- LAB 00-03 — Terraform Installation
- LAB 00-04 — First Azure Resource
- LAB 00-05 — Environment Validation
- LAB 00-06 — Break/Fix — Wrong Subscription
- LAB 00-07 — Challenge — Rebuild Your Environment

## Evidence

Version output, authenticated account, subscription ID, Terraform validation and Azure resource evidence.

## Challenge

Rebuild the workstation checks from the requirements without following a recipe.

## Definition of Done

The learner can independently explain and reproduce the complete environment.
