# COURSE 00 — Learner & Lab Environment Onboarding

## Mission

Prepare a completely new learner to work independently with Git, Azure CLI, Terraform, PowerShell and VS Code.

## Labs

- **00-01 Toolchain** — install/check every tool and diagnose PATH/version problems.
- **00-02 Azure Authentication** — authenticate, inspect tenant/subscription context and select the correct subscription.

## Learner workflow

For every step:

1. Run the command.
2. Read the output.
3. Identify what the output proves.
4. Record evidence.
5. Continue only when the checkpoint passes.

## Completion

The learner must be able to clone the repository, open a lab workspace, authenticate to Azure and explain the active tenant/subscription without instructor intervention.
