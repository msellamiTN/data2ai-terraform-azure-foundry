# LAB 00-03 — Terraform Installation

## Business Scenario
Terraform is the IaC engine used throughout the Academy.

## Mission
Install or verify a supported Terraform CLI and prove it is executable.

## Learning objectives
- inspect Terraform version;
- understand PATH resolution;
- distinguish Terraform CLI failure from Azure provider failure.

## BUILD
Install or expose Terraform in the learner workstation.

## VALIDATE
Run version and formatting/validation smoke checks.

## BREAK
Use a controlled shell with an invalid PATH entry or invoke an intentionally unavailable command.

## FIX
Diagnose executable resolution and restore the environment.

## CHALLENGE
Create a portable environment check for another learner.

## SOLUTION
Review the reference check only after completion.

## CLEANUP
Remove temporary installation artifacts when applicable.
