# LAB 00-04 — First Azure Resource

## Business Scenario
Before learning advanced IaC, prove the end-to-end path from workstation to Azure.

## Mission
Create one low-risk Azure resource and capture evidence.

## Learning objectives
- connect authentication to resource deployment;
- identify resource group and resource IDs;
- distinguish local configuration from cloud state.

## BUILD
Create a dedicated training Resource Group using the prescribed lab configuration.

## VALIDATE
Query the resource with Azure CLI and record its resource ID and provisioning state.

## BREAK
Use a controlled wrong resource-group name or wrong subscription context.

## FIX
Diagnose the mismatch and repair it without copying the solution.

## CHALLENGE
Recreate the resource with a different valid name and tags while preserving the acceptance criteria.

## SOLUTION
Compare implementation choices after the challenge.

## CLEANUP
Delete the training resource group and verify deletion.
