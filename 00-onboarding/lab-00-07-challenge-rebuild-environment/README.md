# LAB 00-07 — Challenge: Rebuild Your Environment

## Business Scenario
You are given a clean workstation and must prepare it for the Academy.

## Mission
Meet the environment acceptance criteria independently.

## Requirements
Git, PowerShell, Azure CLI, Terraform, authenticated Azure context and evidence report.

## Constraints
No solution folder. No copy/paste from previous lab commands. Use the documented requirements only.

## Acceptance
A second learner can reproduce your environment checks and understand every PASS/FAIL result.

## Evidence
Environment report plus Azure context evidence.

## CLEANUP
Remove temporary files and test resources.
