# Course 01 — Azure Enterprise Foundations

## Outcome

Understand Azure resource hierarchy, identity, authorization, governance and networking well enough to reason about AI infrastructure before introducing Terraform.

## Lessons

1. Azure hierarchy and resource boundaries
2. Resource Groups and regions
3. Entra identity
4. RBAC: Identity → Role → Scope → Permission → Resource
5. Managed Identity
6. Azure CLI resource inspection
7. Governance and tagging
8. Network fundamentals

## Labs

- 01-01 Resource Hierarchy
- 01-02 Resource Group Boundaries
- 01-03 Azure CLI Deployment
- 01-04 RBAC Investigation
- 01-05 Managed Identity
- 01-06 Governance Baseline
- 01-07 Break/Fix — RBAC Scope
- 01-08 Challenge — DEV Resource Boundary

## Definition of Done

The learner can diagnose an Azure authorization problem from evidence instead of guessing permissions.
