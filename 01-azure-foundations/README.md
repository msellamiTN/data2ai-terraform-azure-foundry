# COURSE 01 — Azure Foundations for AI Engineers

## Mission

Build Azure fundamentals through observable CLI operations before introducing infrastructure as code.

## Labs

- **01-01 First Resource** — create and inspect a Resource Group.
- **01-02 Azure CLI** — discover, filter, inspect and remove resources.
- **01-03 RBAC** — identify identity, role and scope and diagnose permission failures.

## Build principle

Start from Azure operations, not Terraform. Learners must understand the target platform before automating it.

## Required observations

Learners inspect:

```text
subscription
resource group
resource
location
tags
identity
role
scope
```

## Break/Fix

Wrong subscription, invalid region/name and insufficient permissions must be diagnosed from command output rather than guessed.
