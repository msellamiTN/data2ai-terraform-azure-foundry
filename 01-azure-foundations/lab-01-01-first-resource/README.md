# lab-01-01-first-resource — first resource

> **Data2AI Academy — Professional Hands-on Lab**

## Business scenario
An engineering team needs a repeatable, reviewable capability for an Azure AI platform.

## Mission
Build the capability, validate it with evidence, then diagnose a controlled failure.

## Learning loop
**LEARN → BUILD → VALIDATE → BREAK → FIX → CHALLENGE → SOLUTION**

## Prerequisites
- Git
- Azure CLI authenticated to the intended subscription
- Terraform for Terraform labs
- PowerShell or Bash
- No credentials or production secrets in the repository

## Tasks
1. Inspect the starter material and identify inputs, dependencies and expected behavior.
2. Implement the smallest correct change.
3. Run formatting and validation checks.
4. Review the plan before applying infrastructure changes.
5. Execute validation and capture evidence.

## Break/Fix
Use **Symptom → Evidence → Diagnosis → Root Cause → Fix → Validation → Prevention**.

## Challenge
Change one meaningful requirement without changing the learning objective. Explain the design decision and prove the result.

## Cleanup
Remove only resources created for the lab and verify the target scope is clean.

## Reference solution
Open only after completing the challenge. Compare decisions, not just code.
