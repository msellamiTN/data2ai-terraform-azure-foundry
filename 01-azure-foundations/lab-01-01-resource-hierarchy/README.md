# LAB 01-01 — Explore Azure Resource Hierarchy

## Business Scenario
An AI platform team needs a clear ownership boundary before provisioning resources.

## Mission
Map Tenant → Subscription → Resource Group → Resource.

## Learning objectives
Explain the hierarchy and identify the scope at which controls apply.

## BUILD
Inspect an existing training subscription and resource group.

## VALIDATE
Produce resource IDs and parent relationships as evidence.

## BREAK
Investigate a resource from an unexpected resource group.

## FIX
Trace the actual hierarchy from Azure evidence.

## CHALLENGE
Document the hierarchy for a new DEV workload without deploying it.

## SOLUTION
Compare the reasoning after completion.

## CLEANUP
No persistent changes required.
