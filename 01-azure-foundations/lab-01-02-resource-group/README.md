# LAB 01-02 — Resource Group Boundaries

## Business Scenario
A DEV AI workload requires an explicit lifecycle boundary.

## Mission
Create and inspect a Resource Group with naming and tags.

## BUILD
Create the Resource Group using Azure CLI.

## VALIDATE
Verify location, tags, ID and provisioning state.

## BREAK
Use an incorrect location or missing required tag.

## FIX
Diagnose from Azure CLI output and correct the configuration.

## CHALLENGE
Define a second DEV boundary with a different workload owner.

## CLEANUP
Delete the training Resource Group after evidence capture.
