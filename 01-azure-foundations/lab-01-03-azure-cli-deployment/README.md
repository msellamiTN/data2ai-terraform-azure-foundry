# LAB 01-03 — Deploy with Azure CLI

## Business Scenario
A platform engineer needs a repeatable CLI deployment before translating the workflow to Terraform.

## Mission
Deploy a low-risk Azure resource from explicit parameters.

## BUILD
Create the resource and capture the command inputs.

## VALIDATE
Query the actual resource and compare it with the intended configuration.

## BREAK
Change one deployment parameter to produce a controlled mismatch.

## FIX
Use Azure evidence to identify and correct the mismatch.

## CHALLENGE
Reproduce the deployment with a different valid configuration while keeping the same acceptance criteria.

## CLEANUP
Remove training resources.
