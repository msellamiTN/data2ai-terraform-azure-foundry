# LAB 01-04 — RBAC Investigation

## Business Scenario
An engineer can authenticate to Azure but cannot perform a required operation.

## Mission
Investigate authorization using Identity → Role → Scope → Permission → Resource.

## BUILD
Inspect the identity and applicable role assignments.

## VALIDATE
Prove which scope and role govern the operation.

## BREAK
Use a deliberately insufficient role or scope in a controlled environment.

## FIX
Diagnose the missing permission and apply the minimum required correction.

## EXPLAIN
Explain why authentication success does not imply authorization success.

## CHALLENGE
Design a least-privilege assignment for a DEV resource boundary.

## CLEANUP
Remove temporary role assignments.
