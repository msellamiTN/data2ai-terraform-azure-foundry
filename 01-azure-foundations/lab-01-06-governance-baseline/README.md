# LAB 01-06 — Governance Baseline

## Business Scenario
An enterprise AI platform needs consistent metadata and ownership.

## Mission
Apply a small governance baseline using tags and naming conventions.

## BUILD
Create resources using the agreed naming and tagging contract.

## VALIDATE
Query tags and names from Azure.

## BREAK
Create a controlled non-compliant resource.

## FIX
Detect and remediate the compliance gap.

## CHALLENGE
Extend the contract with one additional governance attribute and explain why.

## CLEANUP
Delete training resources.
