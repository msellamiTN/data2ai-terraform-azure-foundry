# LAB 01-07 — Break/Fix: RBAC Scope

## Business Scenario
A learner receives an authorization error after changing the resource scope.

## Mission
Diagnose the failure without opening the solution.

## BREAK
A role assignment is deliberately attached to the wrong scope.

## FIX
Collect identity, role, scope and resource evidence; correct the assignment; validate the operation.

## EXPLAIN
State the root cause and one prevention mechanism.

## CHALLENGE
Create a scope decision rule for DEV versus shared resources.
