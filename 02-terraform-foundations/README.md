# COURSE 02 — Terraform Fundamentals

## Mission

Build Terraform projects from an empty workspace. The learner creates files, edits HCL, runs Terraform commands and interprets the results.

## Labs

1. **02-01 First Resource** — `main.tf`, provider, Resource Group, plan/apply/state.
2. **02-02 Variables & Outputs** — `variables.tf`, `terraform.tfvars`, outputs.
3. **02-03 Data Sources** — discover existing Azure context.
4. **02-04 State** — inspect and reason about state.
5. **02-05 Import & Drift** — bring brownfield resources under management and detect ClickOps drift.

## Command progression

```text
terraform fmt
terraform init
terraform validate
terraform plan
terraform apply
terraform state list
terraform state show
terraform output
terraform destroy
```

## Mandatory learner behavior

Do not copy the solution. Create the important files yourself and stop after each command to interpret the output.

## Gold-standard lab

**02-01 First Resource** is the reference pattern for all later Terraform labs.
