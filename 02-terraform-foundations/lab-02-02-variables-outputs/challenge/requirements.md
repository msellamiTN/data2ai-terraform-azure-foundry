# Challenge Contract — Variables & Outputs

Build a second environment without changing the resource definition.

Requirements:
1. Use the existing Terraform starter.
2. Create a new `terraform.tfvars`.
3. Change only variable values.
4. Use a distinct Resource Group name.
5. Preserve the required tags.
6. Produce outputs for ID, name, location and tags.
7. Capture `fmt`, `validate`, `plan`, `apply` and independent Azure evidence.
8. Run the validator and obtain `RESULT: PASS`.
9. Destroy the test environment after evidence capture.

Do not open `solution/` until your implementation is complete.
