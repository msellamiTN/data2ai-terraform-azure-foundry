# Challenge Contract — Import & Drift

Import a second existing Resource Group into a new Terraform address.

Requirements:
- create the Resource Group outside Terraform;
- define a matching Terraform resource;
- initialize Terraform;
- import the Azure resource into State;
- inspect the imported state;
- reach an explainable plan;
- introduce one controlled tag drift;
- detect and reconcile the drift;
- document the complete evidence chain;
- clean up deliberately.

The challenge must be completed before reading the reference solution.
