# Course 03 — Enterprise Terraform & Azure Platform Engineering

## Outcome
Design maintainable Terraform repositories with reusable modules, environment isolation, remote state and enterprise conventions.

## Lessons
1. Repository architecture
2. Naming and tagging contracts
3. Variables and module interfaces
4. Reusable modules
5. Azure Verified Modules
6. Remote state
7. DEV / TEST / PROD isolation
8. Brownfield adoption
9. Drift detection
10. Platform composition
11. Testing and validation

## Labs
- 03-01 Module Design
- 03-02 Naming and Tagging
- 03-03 Remote State
- 03-04 Environment Isolation
- 03-05 Platform Module
- 03-06 Azure Verified Module Integration
- 03-07 Brownfield Adoption
- 03-08 Drift Detection
- 03-09 Module Contract Testing
- 03-10 Platform Composition
- 03-11 Challenge — Enterprise Platform Module

## Definition of Done
A learner can design a reusable Terraform module, isolate environments, manage state deliberately and explain module contracts and drift behaviour.
