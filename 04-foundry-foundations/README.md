# Course 04 — Microsoft Foundry Foundations

## Mission
Connect Terraform engineering to an Azure AI platform lifecycle.

## Competencies
Foundry architecture, projects, models, deployments, connections and agents; where AzureRM is sufficient and where API-level resources may be required.

## Labs
Foundation, project exploration, Terraform, model deployment, break/fix.

## Exit criteria
The learner can trace a model request from application to deployed model and identify identity, capacity and configuration dependencies.
