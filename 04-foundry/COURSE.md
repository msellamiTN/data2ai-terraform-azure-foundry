# Course 04 — Microsoft Foundry Platform Engineering

## Outcome
Provision and reason about the infrastructure primitives required for enterprise AI workloads with Microsoft Foundry.

## Lessons
1. Generative AI platform concepts
2. Microsoft Foundry architecture
3. Foundry resources and projects
4. Model catalog and deployments
5. Connections
6. Storage
7. Azure AI Search
8. Managed Identity
9. Key Vault integration
10. Terraform and AzAPI patterns
11. Platform validation

## Definition of Done
The learner can explain the Foundry infrastructure model and provision a validated foundation without hard-coded secrets.
