# LAB 04-02 — Foundry Project

## Scenario
An AI platform separates the shared Foundry foundation from an application project.

## Mission
Model the project boundary, configuration contract and outputs.

## BUILD
Start from the starter folder and implement the project inputs required by the lab environment. Validate before deployment.

## VALIDATE
Prove the project belongs to the expected Foundry foundation and resource group.

## BREAK / FIX
Use the supplied wrong-scope configuration. Diagnose using resource IDs, Azure context and Terraform plan.

## EXPLAIN
Explain why project boundaries matter for governance and lifecycle management.

## CHALLENGE
Create a second project contract for a separate workload without duplicating provider configuration.

## SOLUTION
Inspect the reference after the challenge.

## CLEANUP
Destroy training resources and verify no orphaned resources remain.
