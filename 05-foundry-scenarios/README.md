# COURSE 05 — Foundry AI Scenario Engineering

## Mission

Build complete AI scenarios instead of isolated service demos.

## Scenario labs

1. GenAI Assistant
2. Enterprise RAG
3. AI Agent
4. Document Intelligence
5. Industrial Vision
6. Speech & Language
7. Translator / Multilingual AI
8. Content Safety
9. Content Understanding / Multimodal
10. Multi-Service AI Platform

## Scenario method

For each scenario:

```text
BUSINESS REQUIREMENT
 ↓
ARCHITECTURE
 ↓
AZURE SERVICES
 ↓
TERRAFORM PROJECT
 ↓
DEPLOYMENT
 ↓
FUNCTIONAL VALIDATION
 ↓
BREAK/FIX
 ↓
CHALLENGE
```

The learner must identify the purpose of every Azure component and validate the actual deployed contract.
