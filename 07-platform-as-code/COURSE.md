# Course 07 — Enterprise AI Platform as Code

## Outcome
Compose reusable platform capabilities into a governed AI landing platform.

## Platform modules
foundry / project / model / storage / search / key-vault / identity / networking / monitoring / governance

## Labs
- 07-01 Platform Module
- 07-02 Module Composition
- 07-03 Variable and Output Contracts
- 07-04 Environment Composition
- 07-05 Brownfield Import
- 07-06 Drift Remediation
- 07-07 Platform Validation
- 07-08 Challenge — Enterprise AI Platform

## Definition of Done
The learner can compose modules without duplicating platform logic and can prove the resulting platform contract.
