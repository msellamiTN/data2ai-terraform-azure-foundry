# Course 08 — AI Platform DevSecOps

## Outcome
Automate quality, security, planning, approval and evidence across the Terraform AI platform lifecycle.

## Lessons
1. Git workflow
2. Pull Requests
3. Terraform formatting and validation
4. Static analysis
5. Security scanning
6. Plan generation
7. Approval gates
8. DEV → TEST → PROD
9. Release evidence

## Labs
- 08-01 Git and PR Workflow
- 08-02 Terraform Quality
- 08-03 Security Scanning
- 08-04 Terraform Plan Pipeline
- 08-05 Approval Gate
- 08-06 Environment Promotion
- 08-07 Evidence and Release
- 08-08 Challenge — AI Platform Pipeline

## Definition of Done
A platform change is reviewable, validated, security-checked and promoted through controlled stages.
