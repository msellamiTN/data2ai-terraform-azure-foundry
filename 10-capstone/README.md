# Course 10 — Enterprise Agentic AI Platform — Capstone

**Level:** Advanced | **Mode:** Open Engineering Challenge

## Mission

Design, implement, validate, secure, operate and defend a production-style Agentic AI platform.

## Business scenario

An enterprise requires a secure AI platform for an Agentic AI workload with grounded knowledge, controlled access, automation, observability and cost governance.

## Requirements

- Azure
- Terraform
- Microsoft Foundry
- AI Agent
- AI Search
- Storage
- Key Vault
- Managed Identity
- RBAC
- Monitoring
- CI/CD
- FinOps
- Documentation

## Constraints

- No manual production deployment.
- No hard-coded secrets.
- Reusable Terraform modules.
- Environment separation.
- Evidence required.
- Security model required.
- Operational model required.

## Deliverables

1. Terraform repository
2. Architecture diagram
3. README
4. Infrastructure design
5. Security model
6. CI/CD pipeline
7. Monitoring design
8. FinOps strategy
9. Validation evidence
10. Troubleshooting report
11. ADRs
12. Final engineering defense

## Evaluation evidence

The learner must demonstrate the platform, explain decisions, reproduce a failure, diagnose it from evidence, repair it, prove the repair and defend the resulting architecture.

## Rule

There is **no step-by-step implementation recipe** for the capstone.
