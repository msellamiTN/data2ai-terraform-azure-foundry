# Course 10 — Enterprise AI Platform Capstone

## Mission
Integrate Terraform, Foundry, security, CI/CD, monitoring and FinOps into an auditable enterprise platform.

## Required deliverables
Terraform repository, architecture diagram, README/runbook, security model, CI/CD workflow, monitoring design, FinOps strategy, validation evidence and troubleshooting report.

## Reference target
Git → Terraform → DEV/PROD → Foundry + Search + Storage + Key Vault → Managed Identity/RBAC → Monitoring → FinOps.
