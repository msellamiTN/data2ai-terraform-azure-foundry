# Course 10 — Enterprise AI Platform Capstone

## Mission
Deliver an enterprise AI platform without a step-by-step recipe.

## Required deliverables
1. Terraform repository
2. Architecture diagram
3. README and deployment runbook
4. Security model
5. CI/CD workflow
6. Monitoring design
7. FinOps strategy
8. Validation evidence
9. Troubleshooting report

## Reference target
Git → Terraform → DEV/PROD → Foundry + Search + Storage + Key Vault → Managed Identity/RBAC → Monitoring → FinOps.
