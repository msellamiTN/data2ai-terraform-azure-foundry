# COURSE 10 — Enterprise AI Platform Capstone

## Mission

Build an enterprise AI platform from a requirements contract, without a step-by-step recipe.

## Expected architecture

```text
Git
 ↓
Terraform
 ↓
DEV / TEST / PROD
 ↓
Foundry + Search + Storage + Key Vault
 ↓
Managed Identity + RBAC
 ↓
Monitoring + Governance + FinOps
```

## Deliverables

- Terraform repository
- reusable modules
- environment strategy
- architecture diagram
- security model
- CI/CD
- validation/tests
- monitoring
- FinOps strategy
- troubleshooting report
- evidence
- README

## Completion standard

The learner must demonstrate that the platform can be reproduced from code and that every critical requirement can be independently validated.
