# DATA2AI Elite Course Standard

Every course is delivered as an engineering system.

## Required flow
BUSINESS SCENARIO → REQUIREMENTS → ARCHITECTURE → THREAT MODEL → ADR → DESIGN → BUILD → VALIDATE → BREAK → DIAGNOSE → FIX → EXPLAIN → AUTOMATE → OPTIMIZE → DEFEND

## Required lab classes
- Build Lab: guided implementation with explicit acceptance criteria.
- Practice Lab: reduced guidance; learner makes design and implementation decisions.
- Break/Fix Lab: one controlled defect; evidence before changes.
- Challenge Lab: requirements only; no procedural steps.
- Production Simulation: time-boxed incident, change or architecture review.

## Required lab sections
1. Business Scenario
2. Mission
3. Requirements
4. Architecture
5. Threat Model
6. Prerequisites
7. Starter Environment
8. Guided Tasks
9. Validation
10. Break/Fix
11. Challenge
12. Reference Solution
13. Cleanup
14. Evidence checklist

## Troubleshooting contract
SYMPTOM → EVIDENCE → DIAGNOSIS → ROOT CAUSE → FIX → VALIDATION → PREVENTION

Never accept “it works” without evidence.

## READY gate
A course is READY only when implementation is executable, validation is automated, failures are reproducible, challenge is independently solvable, solution is complete, cleanup is documented, security is reviewed, instructor guidance exists, learner evidence is defined, and CI/CD plus Pages integration are validated.
