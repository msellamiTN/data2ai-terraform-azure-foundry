# Data2AI Terraform Azure AI Foundry

Self-paced, hands-on academy for engineering Microsoft Azure AI Foundry infrastructure with Terraform.

> **Read less. Build more. Break it. Fix it. Explain it. Automate it.**

## Learning model

**LEARN → BUILD → VALIDATE → BREAK → FIX → CHALLENGE → SOLUTION**

## Repository conventions

Each lab follows:

`starter/` → `broken/` → `validation/` → `solution/`

Solutions are separated from learner material so learners can attempt challenges independently.
