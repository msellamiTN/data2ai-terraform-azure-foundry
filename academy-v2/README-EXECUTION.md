# DATA2AI Academy Execution Guide

Execute one lab at a time.

For every lab:
1. Read scenario and requirements.
2. Inspect architecture and decisions.
3. Execute starter/practice work.
4. Run validation.
5. Capture baseline evidence.
6. Execute Break/Fix.
7. Complete the challenge without the solution.
8. Compare with the reference solution.
9. Clean up.
10. Send DATA2AI feedback.
