# Elite Competency Model

Assessment measures engineering competence, not command memorization.

## Dimensions

1. Architecture reasoning
2. Terraform engineering
3. Azure platform engineering
4. AI/agent engineering
5. Security by design
6. Validation and testing
7. Troubleshooting
8. Automation
9. Observability and reliability
10. FinOps and governance
11. Technical communication
12. Production defense

## Evidence chain

**Symptom → Evidence → Diagnosis → Root Cause → Fix → Validation → Prevention**

A learner receives completion evidence only when the chain is demonstrated.

## Challenge principle

Reference solutions remain hidden until the learner has attempted diagnosis and recovery.
