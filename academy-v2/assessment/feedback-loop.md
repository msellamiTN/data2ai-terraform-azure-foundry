# DATA2AI Lab Feedback Loop

Learner feedback is treated as product telemetry.

## Lifecycle
EXECUTE → CAPTURE → REPORT → REPRODUCE → DIAGNOSE → FIX → RE-RUN → UPDATE → RELEASE

## Categories
Environment, prerequisites, documentation, Terraform, Azure, identity/RBAC, networking, AI/agent behavior, evaluation, security, observability, cost, pedagogy.

A failure is not automatically a training defect. Reproduce it before changing the material.
