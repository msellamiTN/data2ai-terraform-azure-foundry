# 00 — Academy & Engineering Environment

## Mission
Build a reproducible workstation and evidence discipline before touching enterprise infrastructure.

## Modules
1. Git and repository operating model
2. Azure CLI and subscription context
3. PowerShell and Bash interoperability
4. Terraform CLI lifecycle
5. Azure authentication and identity evidence
6. Validation scripts and failure capture
7. Safe cleanup and cost awareness

## Labs
- L00-01: Verify workstation
- L00-02: Azure identity and subscription evidence
- L00-03: Git branch/commit workflow
- L00-04: Controlled authentication failure
- L00-05: Build a learner validation harness

## Break/Fix
Wrong subscription, expired authentication, missing executable, wrong working directory, malformed Terraform variables.

## Exit evidence
The learner can reproduce the environment from a clean machine and explain every prerequisite rather than relying on undocumented local state.
