# Course 00 Labs

## L00-01 — Workstation Readiness
Verify Git, Azure CLI, PowerShell/Bash, Terraform and repository access. Evidence must include tool versions, authenticated identity, subscription context, Git remote and Terraform version.

## L00-02 — Identity Evidence
Prove which Azure identity and subscription are active. Break the subscription context and diagnose it from evidence.

## L00-03 — Validation Harness
Build a validator that returns PASS/FAIL and RESULT: READY. Break a prerequisite and prove the validator detects it.

## L00-04 — Clean-Machine Challenge
Starting from prerequisites only, reproduce the workstation and produce an evidence bundle.
