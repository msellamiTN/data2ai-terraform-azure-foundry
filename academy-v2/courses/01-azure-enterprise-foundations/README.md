# 01 — Azure Enterprise Foundations

## Mission
Reason about Azure as an enterprise platform: identity, resource hierarchy, networking, governance and operational boundaries.

## Modules
1. Tenant, Entra ID, subscriptions and management groups
2. Resource groups and ownership boundaries
3. RBAC and least privilege
4. Hub-and-spoke networking
5. Private endpoints and private DNS
6. Azure Policy and governance
7. Monitoring and cost boundaries
8. Landing-zone workload placement

## Labs
- L01-01: Resource-group ownership model
- L01-02: Group-based RBAC
- L01-03: Hub/spoke design exercise
- L01-04: Private endpoint and DNS diagnosis
- L01-05: Policy-as-code challenge

## Break/Fix
RBAC denial, wrong scope, DNS resolution failure, blocked egress, policy denial.

## Exit evidence
A learner can explain where a workload belongs, who owns it, how it is isolated and how access is governed.
