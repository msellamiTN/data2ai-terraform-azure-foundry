# 05 — Agentic AI Engineering

## Mission
Engineer agents as governed software systems rather than prompts.

## Agent complexity ladder
0. Direct model call
1. Single agent
2. Agent + tools
3. RAG agent
4. Sequential agents
5. Concurrent agents
6. Handoff/group chat
7. Dynamic/magentic orchestration
8. Enterprise agent platform

Use the lowest complexity that reliably meets requirements.

## Modules
1. Agent contracts
2. Instructions and prompts as versioned artifacts
3. Tool contracts and schemas
4. RAG architecture
5. Memory and context
6. Orchestration patterns
7. Human approval
8. Evaluation-driven development
9. Agent observability
10. Failure recovery

## Agent contract
identity · scope · authority · tools · contracts · inputs · outputs · limits · telemetry · evaluation · escalation

## Key principle
**Prompt ≠ Security Control.**
Authorization is deterministic and external to probabilistic reasoning.
