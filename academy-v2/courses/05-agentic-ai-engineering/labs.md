# Course 05 Labs

## L05-01 — Single Agent
Implement a bounded enterprise agent with explicit instructions and output contract.

## L05-02 — Tool-Using Agent
Expose a deterministic tool through a typed contract.

## L05-03 — Secure RAG
Implement retrieval with access-aware data boundaries.

## L05-04 — Sequential Workflow
Compose bounded agents with explicit handoff contracts.

## L05-05 — Evaluation Harness
Create test cases, expected behavior and regression evidence.

## L05-06 — Runaway Loop
Introduce an agent loop failure. Diagnose using telemetry and implement bounded recovery.

## L05-07 — Agent Platform Challenge
Choose the lowest-complexity orchestration that satisfies a stated enterprise scenario.
