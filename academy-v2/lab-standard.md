# DATA2AI Academy — Lab Standard

## Required structure

```
lab-XX/
├── README.md
├── starter/
├── practice/
├── broken/
├── validation/
├── challenge/
└── solution/
```

## README contract

1. Business Scenario
2. Mission
3. Learning Objectives
4. Architecture
5. Prerequisites
6. Starter Environment
7. BUILD
8. VALIDATE
9. BREAK
10. FIX
11. EXPLAIN
12. CHALLENGE
13. SOLUTION
14. CLEANUP
15. Evidence checklist
16. Troubleshooting

## Troubleshooting contract

**SYMPTOM → EVIDENCE → DIAGNOSIS → ROOT CAUSE → FIX → VALIDATION → PREVENTION**

## Rules

- Never expose the solution during the challenge.
- Validators must test the actual contract, not only syntax.
- Break/Fix must be reproducible and safe.
- Every Azure resource created by training must have a cleanup path.
- No secrets in Git.
