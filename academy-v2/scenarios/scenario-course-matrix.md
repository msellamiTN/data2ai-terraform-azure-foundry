## How to use the matrix

A course lab selects one scenario and one capability. The scenario business context must remain visible throughout the lab. Learners should be able to explain why the architecture exists before implementing it.

The same scenario can reappear at increasing maturity without duplicating the same exercise:

Business Need → Architecture → Platform → Agent → Security → Evaluation → Operations → Production Defense
