# 06 — Secure Enterprise AI Platform

## Mission
Apply security by design across identity, network, data, tools, agents and operations.

## Modules
1. Threat modeling for AI systems
2. Zero Trust boundaries
3. Entra ID and managed identity
4. RBAC and least privilege
5. Key Vault and secretless design
6. Private Link and network isolation
7. Policy-as-code
8. Secure RAG and data filtering
9. Tool authorization
10. Content safety and human oversight
11. Auditability and traceability

## Labs
- L06-01: Threat model an AI workload
- L06-02: Secretless agent platform
- L06-03: Private AI platform
- L06-04: Tool authorization gate
- L06-05: Security regression challenge

## Break/Fix
Over-privileged identity, missing private DNS, public exposure, unauthorized tool invocation and data-boundary regression.

## Exit evidence
The learner can identify a trust boundary, name the control, implement it and prove it with evidence.
