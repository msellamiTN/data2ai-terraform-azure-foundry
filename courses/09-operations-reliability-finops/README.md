# 09 — AI Platform Operations, Reliability & FinOps

## Mission
Operate AI infrastructure and agents with measurable reliability, observability and cost discipline.

## Modules
1. SLO/SLI thinking
2. Metrics, logs and traces
3. Agent traces and evaluation telemetry
4. Alerting and incident response
5. Failure budgets
6. Model and inference cost
7. Search/storage/network cost
8. Resource tagging and chargeback
9. Optimization and capacity
10. Operational runbooks

## Labs
- L09-01: Observability baseline
- L09-02: Agent trace investigation
- L09-03: Reliability incident
- L09-04: Cost attribution
- L09-05: FinOps optimization challenge

## Break/Fix
Missing telemetry, alert blind spot, cost anomaly, excessive agent loops and degraded retrieval.

## Exit evidence
The learner can detect, diagnose, communicate and remediate an AI platform incident while explaining its cost impact.
