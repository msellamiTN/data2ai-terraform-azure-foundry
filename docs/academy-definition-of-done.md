# Academy Definition of Done

The Academy is READY only when every course has learner content and executable implementation.

## Required
- Course guide and lesson sequence
- Lab README
- Starter code
- Validation scripts
- Reproducible Break/Fix
- Challenge without solution leakage
- Reference solution
- Cleanup
- Evidence checklist
- Troubleshooting
- CI validation
- GitHub Pages publication

## Engineering loop
LEARN → BUILD → VALIDATE → BREAK → FIX → EXPLAIN → CHALLENGE → SOLUTION → CLEANUP
