# Data2AI Academy — Terraform + Azure AI Foundry

> **Build-first. Self-paced. Evidence-driven.**

This GitHub Pages site is the learner-facing execution layer for the Data2AI Academy repository.

## Our learning philosophy

**Read less. Build more. Break it. Fix it. Explain it. Automate it.**

Every executable lab follows the engineering loop:

```text
LEARN
  ↓
BUILD
  ↓
VALIDATE
  ↓
BREAK
  ↓
FIX
  ↓
CHALLENGE
  ↓
SOLUTION
  ↓
CLEANUP
```

The objective is not to memorize Terraform syntax or Azure AI Foundry terminology. The objective is to **engineer, validate, troubleshoot, secure, and automate AI infrastructure**.

## How to use these pages

1. Open a lab from **Lab Navigation**.
2. Read only the context needed to start.
3. Execute the commands in your own `student-work` directory.
4. Capture evidence from Terraform, Azure CLI, and validation scripts.
5. Complete the Break/Fix scenario without opening the solution first.
6. Complete the Challenge independently.
7. Compare your implementation with the Reference Solution.
8. Clean up Azure resources when the lab is complete.

## Lab model

| Stage | Learner behavior | Evidence |
|---|---|---|
| **LEARN** | Understand the engineering objective | Concept/checkpoint |
| **BUILD** | Create or modify the implementation | Files + commands |
| **VALIDATE** | Prove the expected state | Validator + Azure evidence |
| **BREAK** | Reproduce a controlled failure | Failure output |
| **FIX** | Diagnose and repair it | Before/after evidence |
| **CHALLENGE** | Solve a new requirement independently | Working implementation |
| **SOLUTION** | Compare engineering decisions | Reference implementation |
| **CLEANUP** | Remove training resources safely | Azure state |

## Definition of Done

A lab is complete when the learner can:

- explain the architecture and engineering objective;
- execute the implementation without copying the solution;
- validate the real contract, not only Terraform syntax;
- diagnose a deliberate failure from evidence;
- repair the configuration and prove the fix;
- complete the independent challenge;
- explain the design choices;
- clean up the training environment.
