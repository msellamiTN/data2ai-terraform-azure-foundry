# Course Map

## 00 — Onboarding
Git, Azure CLI, Terraform, PowerShell, VS Code, authentication and environment checks.

## 01 — Azure Foundations
Cloud concepts, tenant, subscription, resource group, regions, resources, Azure CLI, identity and RBAC.

## 02 — Terraform Fundamentals
IaC, HCL, providers, resources, variables, outputs, dependencies, data sources, state, import and drift.

## 03 — Terraform on Azure
Project structure, naming, tagging, modules, remote state, environments, validation and testing.

## 04 — Foundry Foundations
Generative AI concepts, Foundry architecture, projects, models, deployments, connections and agents.

## 05 — Foundry Scenarios
GenAI assistant, RAG, agents, document intelligence, vision, speech/language, translation, safety, multimodal and multi-service platforms.

## 06 — Security
Managed identity, RBAC, Key Vault, VNet, private endpoints and private DNS.

## 07 — Enterprise Terraform
Module architecture, versioning, environment strategy, secrets, brownfield import, drift and testing.

## 08 — DevOps
Git workflow, Terraform CI/CD, DEV→TEST→PROD and governance.

## 09 — Observability & FinOps
Azure Monitor, AI observability, governance, budgets, alerts, tagging and cost allocation.

## 10 — Capstone
An enterprise AI platform delivered as an infrastructure-as-code project with architecture, security, CI/CD, monitoring, FinOps and validation evidence.
