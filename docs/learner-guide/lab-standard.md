# Standard Lab Specification

Every lab should contain:

1. Business Scenario
2. Mission
3. Architecture
4. Prerequisites
5. Starter Environment
6. Guided Tasks
7. Validation
8. Break/Fix
9. Challenge
10. Reference Solution
11. Cleanup

## Lab repository structure

```text
lab-XX/
├── README.md
├── starter/
│   ├── main.tf
│   ├── variables.tf
│   ├── outputs.tf
│   └── terraform.tfvars.example
├── broken/
├── validation/
│   ├── validate.ps1
│   ├── validate.sh
│   └── expected.json
└── solution/
```
