# Data2AI Academy — Learning Methodology

The program is competency-based and lab-first. Concepts are introduced only when they unlock the next engineering task.

## Learning loop
1. **Learn** — minimum theory and vocabulary.
2. **Build** — implement the capability.
3. **Validate** — produce observable evidence.
4. **Break** — reproduce a realistic failure.
5. **Fix** — diagnose from evidence, not guesses.
6. **Challenge** — solve a controlled variation independently.
7. **Solution** — compare decisions with the reference implementation.

## Professional rule
A green `terraform apply` is not sufficient. The learner must understand resource ownership, dependencies, identity, state, validation and recovery.

## Troubleshooting
**Symptom → Evidence → Diagnosis → Root Cause → Fix → Validation → Prevention**
