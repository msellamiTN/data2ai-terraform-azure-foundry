# Data2AI Academy — Terraform + Azure AI Foundry

> **Engineer AI infrastructure. Don’t just learn commands.**

This GitHub Pages site is the learner-facing execution layer for the Academy.

## Learning loop

**LEARN → BUILD → RUN → READ OUTPUT → VALIDATE → BREAK → FIX → CHALLENGE → SOLUTION → CLEANUP**

## Microsoft Learning-style lab experience

Each exercise is published as:

`/Instructions/Exercises/<lab-name>.html`

Every lab contains Mission, Objectives, Prerequisites, Architecture, Tasks, Validation, Break/Fix, Challenge, Cleanup and Definition of Done.

The Pages site is generated automatically from lab `README.md` files in the repository.
