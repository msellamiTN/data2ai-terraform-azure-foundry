# Data2AI Academy — Lab Rubric

| Dimension | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Build | Cannot execute | Executes with heavy help | Executes with limited help | Independent |
| Terraform | Incorrect | Basic implementation | Correct implementation | Clean, explainable engineering |
| Validation | No evidence | Syntax only | Contract validated | Contract + Azure evidence |
| Break/Fix | Cannot diagnose | Finds symptom | Finds root cause | Explains prevention |
| Challenge | Cannot complete | Needs solution guidance | Completes with hints | Independent |
| Explanation | Cannot explain | Describes commands | Explains design | Explains trade-offs |
| Cleanup | Missing | Partial | Complete | Complete and verified |

## Completion rule

A lab is complete when no critical dimension is below **2** and the learner demonstrates independent Challenge completion.

The rubric measures demonstrated competency; it is not a substitute for learner evidence.
