# Data2AI Academy — Learner Guide

## How to learn

This is not a read-and-repeat course.

Use the cycle:

**LEARN → BUILD → VALIDATE → BREAK → FIX → CHALLENGE → SOLUTION → CLEANUP**

## Your rules

- Build in your own workspace.
- Never open the solution first.
- Run the commands.
- Read the errors.
- Capture evidence.
- Ask why before asking what command.
- Break the environment only inside the controlled lab scope.
- Clean up resources after the lab.

## What counts as success?

Not simply: `terraform validate` passed.

Success means: the required infrastructure was built, Azure state was proved, a deliberate failure was diagnosed, the implementation was repaired, the challenge was completed, the architecture was explained, and resources were cleaned up.

## Evidence mindset

For every important action ask:

**What did I expect? What happened? What proves it?**

## Recommended workflow

1. Read the mission.
2. Check prerequisites.
3. Build.
4. Run.
5. Validate.
6. Break.
7. Diagnose.
8. Fix.
9. Challenge.
10. Compare with the solution.
11. Cleanup.
